# Eclipse Fox

This deterministic geometric artwork is rendered entirely in TypeScript with the Node standard library. A lone fox watches a striped coral eclipse beneath teal aurora ribbons, above layered indigo ridges.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The renderer writes a custom-encoded 1024×1024 RGB PNG to `entry.png`. The output directory defaults to `/output`.
